# PSNF ERP

## Mission

Build a modular ERP platform for NGO-operated special-needs schools.

The platform must centralize:

- Student Management
- Parent Communication
- Attendance
- Transport
- Medical Records
- Document Generation
- HR Operations

while supporting:

- Multi-school architecture
- Multi-branch architecture
- Shared database
- Shared authentication
- Module independence

---

## Core Philosophy

Inspired by Odoo.

Users enter through:

Module Launcher

not

Dashboard

Every module acts as an independent application.

Each module has:

- Own routes
- Own controllers
- Own models
- Own services
- Own sidebar

while sharing:

- Authentication
- RBAC
- Notifications
- Audit Logs
- Database
