# Vision

Build a modular ERP platform for NGO-operated special-needs schools.

The platform must support multiple schools, multiple user roles, transport operations, academic management, medical records, document generation, and administrative workflows.

The architecture follows an Odoo-inspired model:

* Module Launcher Dashboard
* Independent Modules
* Shared Authentication
* Shared Database
* Shared Notifications
* Shared Permissions

Primary Users:

* Super Admin
* Admin
* Manager
* Teacher
* Staff
* Driver
* Parent
* Student

Core Principles:

1. Module Independence
2. Shared Data Ownership
3. Multi-School Support
4. Auditability
5. Accessibility
6. Mobile Friendly
7. Scalable Architecture

Special Needs Requirements:

* Disability Records
* Medical Records
* Transport Monitoring
* Parent Communication
* Emergency Information

Document System:

A Canva-style document designer capable of generating:

* Certificates
* Invoices
* Receipts
* Salary Slips
* ID Cards
* Letters

with bulk generation and QR verification support.
